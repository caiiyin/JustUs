## 4. 이미지 안내

- 경로 기준: `public/images/<path>`
- 장소 이미지는 `public/images/places/` 하위에 JPG 포맷으로 저장
- 이미지 파일명은 Place 항목의 `image` 필드 값과 일치
- 실제 이미지 파일은 별도 에셋 관리 방식으로 추가 (초기 시드 시 placeholder 이미지 사용 가능)
