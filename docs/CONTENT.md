## 1. 장소 (Place)

| 필드 | 설명 |
|------|------|
| `name` | 장소명 |
| `address` | 도로명 주소 |
| `lat` / `lng` | 위도 / 경도 (WGS84) |
| `category` | 역사·문화 / 자연·경관 / 체험·액티비티 / 미식·시장 / 예술·전시 / 숙박 |

## 3. 이미지 안내

- 경로 기준: `public/images/<path>`
